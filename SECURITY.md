# Security Policy

## Reporting a Vulnerability
If you find a security issue in this project, do not open a public GitHub issue. Email
mfrabbi.ai@gmail.com with a description, reproduction steps, and impact assessment.
Expect an acknowledgment within 72 hours.

## Scope
This repository is a portfolio project demonstrating production security patterns (RLS
multi-tenancy, prompt-injection defenses, PII redaction, signed inter-agent messaging,
audit logging). It is not currently handling real user data in production.

## Authorized Testing Only
Any security testing against a deployed instance of this project, including the public
demo once live, requires prior written authorization. Unauthorized penetration testing,
load testing, or exploitation attempts against live infrastructure are not permitted.
